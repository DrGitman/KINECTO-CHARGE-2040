# Missed taps and corrections

An unreadable cuff tag, an offline reader or a forgotten jacket should not automatically make a student absent without a way to raise the issue.

A student can send an attendance query to the lecturer. The lecturer checks the session and available tap records before deciding whether a correction is needed. When marking someone present by hand, the lecturer selects a reason and may add a note. The system records who made the correction and when.

A repeated tap within 10 seconds is ignored. A Tap OUT without an earlier Tap IN is rejected. A tap for a closed session is rejected. The interface explains why the tap was not accepted.

The local prototype records manual corrections but does not yet support an undo window, server audit logs or automatic fault creation in the separate jacket support interface. Those features remain planned.
