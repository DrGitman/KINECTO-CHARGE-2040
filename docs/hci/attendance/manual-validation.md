- [ ] Tap OUT requires a prior Tap IN.
- [ ] Duplicate IN is rejected; closed-session taps are rejected.
- [ ] Student sees only sample Student 001 records and cannot access admin navigation.

- [ ] Lecturer correction requires a reason and appears in admin audit log.
- [ ] Admin can view reader and room configuration but cannot use lecturer correction controls.
- [ ] Layout is usable at narrow phone width and desktop width.
- [ ] Browser refresh retains local sample data; Reset clears it.
